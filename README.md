# Dimension

Personal site for Dimension: TikTok (@dimensionisinsane), YouTube (@DimensionFPS) and Discord (@dimensiongfx).

## Files
- `index.html` the page
- `style.css` all styling
- `script.js` animations and interactions

## Run locally
Open `index.html` in a browser.

## Host on GitHub Pages
1. Upload these files to the root of a repository.
2. Go to Settings > Pages, choose the `main` branch and `/ (root)`, then save.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
